# Drag Drop — Anki Add-on

Interactive visual drag-and-drop flashcards for **Anki Desktop (Windows, macOS, Linux), AnkiDroid, and AnkiMobile**.

## Overview
**Drag Drop** turns static diagrams, anatomical charts, process maps, labeled illustrations, and multi-category taxonomies into engaging interactive learning cards. Test your active recall by dragging labels to their designated drop zones or sorting items into category buckets.

---

## Installation

### Via Anki Add-on Package (.ankiaddon)
1. Open **Anki**.
2. Go to **Tools** → **Add-ons** (or press `Ctrl+Shift+A` / `Cmd+Shift+A`).
3. Click **Install from file...** and select `drag_drop.ankiaddon`.
4. Restart Anki when prompted.

---

## How to Create Cards

1. In Anki's main screen, click **Add** (or press `A`).
2. Click the **Drag Drop** toolbar icon or select **Drag drop Image** / **DragDrop** note type.
3. Fill out the fields or use the visual interactive editors:
   - **Image Labeling**: Use the **Visual Placement Studio** to place and size target drop zones directly on your image.
   - **Category Sorting**: Use the **Easy Card Creator** to quickly define categories, answers, and decoy distractors.

---

## Settings & Customization

Open **Tools** → **Drag Drop** (or **Tools** → **Add-ons** → select **Drag Drop** → **Config**) to access the clean settings panel:

- **General**: Theme mode (Auto / Light / Dark), Default Layout (Horizontal / Vertical), Font (System Default / Sans-serif / Serif), and Size (Small / Medium / Large).
- **Image Labeling**: Center card on screen, Max card width, Max image height, Auto-shuffle labels, Show score badge, Enable click-to-place, and Use colored feedback.
- **Category Sorting**: Show ✓ / ✗ symbols, Smooth animations, Highlight drop zones, Equal height columns, Auto-evaluate score, and Allow reordering items.
- **Support**: User guide, GitHub issue reporting, and 1-click restore defaults.
