# Drag Drop

**Interactive drag-and-drop flashcards for Anki.**

Drag Drop turns your Anki cards into interactive learning exercises. Drag labels to the correct places on an image, or sort items into the right categories.

It is useful for **anatomy, biology, diagrams, maps, charts, processes, language learning, classification, and other subjects where visual learning and active recall can help.**

## Two Card Types

### Image Labeling

Place labels on an image and create drop zones for the correct answers.

Useful for:

* Anatomy
* Biology
* Geography
* Maps
* Diagrams
* Charts
* Objects
* Processes

### Category Sorting

Create categories and drag answers into the correct category.

You can also add incorrect answers or **distractors** to make the exercise more challenging.

---

## Creating Cards

1. Open **Add** in Anki.
2. Select the **Drag Drop** note type.
3. Choose the type of card you want to create.
4. For image labeling, use **Visual Placement Studio** to place your drop zones.
5. For category sorting, use **Easy Card Creator** to create categories, answers, and distractors.
6. Add the card and start studying.

## Why I Made It

I wanted a more visual and interactive way to study certain topics in Anki.

Some information is easier to remember when you have to **place it, move it, or sort it yourself** instead of only looking at a question and answer.

I originally made this for my own studying and decided to share it with the Anki community.

If you find a useful way to use it that I hadn't thought of, or notice something that could be improved, feel free to share it.
